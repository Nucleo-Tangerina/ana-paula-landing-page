# Caminhos da Inclusão — landing page

Landing de vendas da formação da Teia de Saberes com Ana Paula Jorge. React + Vite, só frontend, publicada na Wix como Custom Element.

```bash
npm install
npm run dev          # desenvolvimento
npm run build:wix    # arquivo único para a Wix: dist-wix/caminhos-landing.js
```

Publicação: `WIX.md` · contexto: `PRODUCT.md` · design: `DESIGN.md` · plano: `PLAN.md` · direção visual: `.impeccable/surfaces/src-app-tsx.md`.
